@AGENTS.md

## Для Claude

**Роль:** составляю промпты для Cursor и ревьюю результат. Код пишу, только если меня прямо об этом попросили.

**Начало сессии:** прочитай docs/status.md. Из docs/plan.md — только раздел текущего дня. Остальные документы открывай, когда они нужны для ответа.

**dotnet** в оболочке может не быть. Тогда не пытайся собирать — попроси у пользователя вывод `dotnet test`.

## Экономия контекста

- Не читай репозиторий целиком: сначала Grep/Glob, потом нужные файлы.
- Ревью — по `git diff`, а не по всем файлам проекта.
- CSV, логи, вывод тестов — `head`/`tail`, никогда целиком.
- Объёмный разбор (логи, много файлов) — отдавай агенту, в основной чат приноси вывод.
- Ответы короткие: вывод, потом детали. Без пересказа того, что пользователь и так видит.

## Команды

- `/next [шаг]` — промпт для Cursor на текущий шаг
- `/review-step` — ревью сделанного агентом reviewer
- `/done <что закрыто>` — обновить docs/status.md
- `/review-layer <путь>`, `/invariants <агрегат>`, `/adr <тема>`
