## Схема правил

`AGENTS.md` — единый источник для всех агентов (Cursor, Claude Code и др.).
`CLAUDE.md` — ссылка на него, чтобы не дублировать.
`.cursor/rules/*.mdc` — узкие правила, привязанные к путям.

Распределение по режимам активации Cursor:

| Правило | Режим | Почему так |
|---|---|---|
| AGENTS.md | Always | Общие границы, нужны в каждом запросе |
| domain, ai-layer, tests, angular, k8s | Auto Attached (globs) | Нужны только при работе с этими путями |
| kafka | Agent Requested | Пути разбросаны, надёжнее по description |
| review-layer, invariants, adr | Manual | Вызываются осознанно |

## Настройка Claude Code

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Импортирует `AGENTS.md` + роль Claude (промпты и ревью, не код) и правила экономии контекста |
| `.claude/rules/*.md` | Те же правила, что `.cursor/rules`, но с `paths:` — грузятся только при работе с подходящими файлами |
| `.claude/settings.json` → `deny` | Жёсткий запрет читать `bin/`, `obj/`, `out/`, миграции, сгенерированный код — это не просьба в тексте, а ограничение клиента |
| `.claude/settings.json` → хук `PreToolUse` | `guard-domain.sh` блокирует запись EF/Kafka/AI/NuGet в `*.Domain`. Правило из `AGENTS.md` превращено из пожелания в проверку |
| `.claude/agents/reviewer.md` | Ревьюер с чистым контекстом: не видел, как писался код, смотрит `git diff` |
| `.claude/commands/next`, `review-step`, `done` | Рабочий цикл: промпт для Cursor → ревью → обновление `docs/status.md` |
| `docs/status.md` | Снимок «где мы»: новый чат читает 20 строк вместо всего плана |

Почему хук, а не строка в правилах: `CLAUDE.md` — контекст, модель может его проигнорировать. Хук выполняется клиентом при каждой записи файла независимо от того, что решила модель.
